# The Edges of House

## Суть игры

Герой — Элиас, скромный картограф и алхимик из приграничного городка Валемар. Его жена, Лира, талантливая травница, тяжело заболела «Каменной Чумой» — болезнью, которая постепенно превращает плоть в холодный, инертный камень. Все известные методы лечения оказались бессильны.

В отчаянии Элиас находит старую карту, нарисованную его же рукой много лет назад, но места на ней он не помнит. Карта ведёт в заброшенное подземелье под Валемаром, где, по легенде, хранится Сердце Камня — источник энергии, породивший Каменную Чуму.

Элиас спускается в подземелье, надеясь уничтожить источник и спасти Лиру.

**То, что происходит в уровне:**

- Герой идёт по коридорам подземелья.
- Сражается с врагами — окаменевшими существами, поражёнными чумой.
- Чем дальше он продвигается, тем больше камень «оживает» вокруг.
- Подземелье реагирует на него — стены трескаются, статуи нападают.

**Главный враг (финал уровня):**

- **Хранитель Сердца Камня** — древний страж, полностью состоящий из живого камня. Он не разумен — это механизм, созданный, чтобы сохранять источник любой ценой.

Во время боя становится ясно: Каменная Чума — это не проклятие, а побочный эффект энергии Сердца Камня.

**Концовка:**
После победы Элиас разрушает Сердце Камня. Подземелье начинает рушиться. Элиас выбирается наружу с последним осколком кристалла.

> Камень перестал расти.
> Чума замерла.
> Лира выжила — но следы камня навсегда остались на её коже.
> Иногда, глядя на старые карты, Элиас думает:
> некоторые пути лучше пройти лишь один раз.

## Сборка

Чтобы собрать исполняемый файл игры, используйте `run.spec` с помощью PyInstaller:

```bash
pyinstaller run.spec
```

## Управление

- **W / A / S / D** или **Стрелки**: Перемещение
- **Shift (Удерживать)**: Бег
- **E**: Взаимодействие (Разговор с NPC, Открыть сундук)
- **Z**: Смена активного предмета
- **Пробел**: Использовать активный предмет
- **F**: Активировать щит
- **R**: Взорвать динамит
- **Q**: Выбросить выбранный предмет
- **1-9**: Выбор предмета в инвентаре
- **ESC**: Пауза / Меню

**Читы (при запуске с --wc):**

- **P**: Переход на уровень 40
- **F5**: Переход на уровень 20
- **F7-F10**: Отладочные функции спавна
